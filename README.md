# Lądownik — Moduł 1: Statku z fizyką spadania

Brief: This small scaffold implements the first module: a lander that falls under gravity. It's a minimal HTML + JS prototype.

Pliki utworzone:
- `index.html` — entry
- `styles.css` — minimal styles
- `src/ship.js` — `Ship` class with `update(dt)` & `draw(ctx)`
- `src/game.js` — main loop, instantiates `Ship`, applies gravity and draws scene
